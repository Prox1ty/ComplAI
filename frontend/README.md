# ComplAI frontend

React + Vite + TypeScript, plain CSS. Four screens: location, upload, progress (SSE), report.

```bash
cd frontend
npm install
npm run dev:mock   # full demo on mock/result.json, no backend needed
npm run dev        # talks to the backend at VITE_API_TARGET (default http://localhost:8000) via /api proxy
npm run build
```

- `mock/result.json` is generated by `python scripts/build_mock_result.py` from `samples/sample_aml_policy.txt`, so offsets always line up. Its citations are short illustrative excerpts of the FATF Recommendations.
- Hover, focus or tap an underlined passage for the finding popup (Escape closes). Overlapping findings merge into one highlight using the highest severity.
- **Export PDF** calls `window.print()`; the print stylesheet keeps underline colours, adds numbered superscripts, and appends the Findings section, gap table and sources.
